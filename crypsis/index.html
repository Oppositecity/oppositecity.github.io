crypsis

Hide any text or file inside a different, ordinary-looking text. Only someone holding the key can get it back.

carry it as
A true description here makes the cover read better. It becomes part of the key.
Salt puts a random number in the key so nobody can guess it from the cover.
engine

How it works: a language model reads the secret and notes, word by word, how expected each piece was — first choice, fourth choice, ninetieth. Then it starts writing from the key and at every step takes the choice with that same rank. The cover and the secret share nothing but that list of ranks, and the key is what turns one back into the other.

Everything runs on this device. The engine downloads once and nothing you type leaves the page. Hide and reveal in the same kind of browser — different hardware can round numbers differently.

After Norelli and Bronstein, LLMs can hide text in other text of the same length. Their paper does the language mode; exact bytes is added here so it can carry files.
