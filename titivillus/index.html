Seed

One · Encoding

Encoding — damage the characters first

This stage works on characters, before any glyph is drawn — so its output is still text you can copy and paste anywhere. Fields decide where the damage lands; operators decide what it does. Everything below then draws whatever comes out.

Two · Construction

Letterform source

Skeleton draws each letter as monoline strokes, so a break opens a bowl and a stray leg reads as part of the letter. Courier traces the real outline, so damage reads as erosion. Both runs them on top of each other.

Failure modes

Intensity

The script

Only bites in Asemic and All three. A character always lands in the same alphabet slot, so marks recur — that recurrence is what makes a page read as written rather than doodled.

The sack

Titivillus filled a sack a thousand times a day with the syllables scribes dropped. Here every edit is kept the same way — stored as an operation, never baked in. That is why a letter you tuned by hand still comes out in the font file, and why the recipe link reproduces it exactly.

Three · Raster

Raster — the end of the line

Pixels, not paths. Nothing after this can recover an outline, so vector and font export switch off while it runs. Clear the layers and they come back.

Export

Vector and font export are off because the raster stage is running. The image is pixels now.

The font file freezes one broken form per character and installs like any other typeface. ASCII only, monospaced, 1000 units per em.
